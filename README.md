# Túpac Katari: La Marcha de los Millones

Descripción: Videojuego de plataformas 2D que recrea la histórica rebelión de Túpac Katari en 1781. El jugador controla a Julián Apaza en su lucha por la libertad de los pueblos andinos, atravesando diferentes niveles que representan hitos históricos del cerco a La Paz.

Género: Plataformas 2D (Side-scroller)
Plataforma Objetivo: PC (Windows)
Tecnologías: Unity 2022+, Lenguaje C#
Estado del Proyecto: Hito 2 - Estructura Base y Prototipo Inicial

Instrucciones para Ejecutar el Proyecto
1. Clonar el repositorio en tu máquina local: 
   `git clone (https://github.com/visaone1/rebelion-katari-2d)`
2. Abrir **Unity Hub** y seleccionar la opción "Add" (Añadir) para buscar la carpeta del proyecto clonado.
3. Asegurarse de tener instalados los módulos de soporte para 2D en Unity.
4. Dentro de Unity, navegar a la carpeta `Assets/_Project/Scenes/` y abrir la escena principal.
5. Presionar el botón **Play** en el editor de Unity para probar el prototipo.
